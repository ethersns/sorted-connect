# Conneck — Product Roadmap

Conneck (formerly SORTED Connect) is a private business development workspace for the founder of SORTED. It covers finding customers, referrers, partners, a co-founder and funding across the UK, then researching, scoring and contacting them.

The roadmap goes milestone by milestone, and each milestone ships something usable. The order follows the founder's priorities: the discovery-to-outreach workflow comes first, and advanced intelligence comes later.

---

## ✅ Milestone 1 — Product surface (done)

Every screen in the sidebar is branded, interactive and runs on clearly labelled sample data (`src/lib/fixtures.ts`, `.example` domains only).

- Daily Action Dashboard: Top 10 Actions ranked from saved records, KPIs, customer funnel, estimated vs confirmed revenue
- Lead Finder: all search controls, the five action buttons, source links and research dates, dedupe by domain, integration status
- All Opportunities: search, filter, sort, tags, bulk actions, CSV export
- Lead Profile: Overview, AI Analysis, Contacts (verified / inferred / not found), Activity, Outreach, Tasks, Sources, Notes, do-not-contact and sole-trader flags
- Sales Pipeline: drag-and-drop kanban for all five pipelines, including closed-out stages
- Outreach Studio: 8 message types and 4 tones, Copy / Regenerate / Edit / Save Draft, PECR warning
- Co-Founder Search: candidate view, Fit Assessment, first-meeting question generator, validation checklist
- Partnerships & Network, Funding & Growth, Tasks & Follow-ups, Growth Advisor (derived insights), Settings (positioning, feature status, integrations, budgets)

## Milestone 2 — Private access and persistent data

- Netlify Identity with **invite-only** registration. Every route and server function requires a logged-in user, so nothing renders before login.
- Netlify Database (Postgres) with a Drizzle schema in `db/schema.ts`. Tables: organisations, people, opportunities, sources/evidence, assessments, activities, outreach drafts, tasks, co-founder assessments, search history, app settings, API usage, do-not-contact.
- Replace the `useWorkspace()` actions in `src/lib/store.tsx` with server functions, keeping the same component API.
- Deduplication on company number, normalised domain and name + postcode.
- CSV import with column mapping and a dedupe preview. Settings persist.
- A separate "demo data" flag so sample records never mix with production records.

## Milestone 3 — Live lead discovery

- Brave Search API (`BRAVE_SEARCH_API_KEY`) for web discovery. Results are batched and paginated, with UK-region-aware query building.
- Companies House API (`COMPANIES_HOUSE_API_KEY`) for name/number lookups, status, SIC codes and registered address.
- A website fetcher that respects robots.txt, pulls a small set of pages (home / about / contact) and extracts public phone, email and contact page. Any field not found stays "Not found".
- Caching of search and page results (Netlify Blobs), retries with backoff, per-provider rate limits.
- Clear error states when a key is missing or a provider fails. Companies House-only and manual entry still work as fallbacks.
- "Find Similar Businesses" built from a saved record's industry, region and keywords.

## Milestone 4 — AI research and outreach

- Netlify AI Gateway, server-side only. Default model `deepseek/deepseek-v4.1-flash`, with provider and model configurable in Settings.
- Fit assessments with separate rubrics for customers (the 30/25/20/15/10 weighting), referrers, partners, funding and co-founders. Outputs: evidence with source URLs, confidence, unknowns, approach, next action and objections.
- Assessments are cached per content hash, so unchanged companies are never re-analysed.
- Outreach Studio drafts generated by AI from verified facts and approved SORTED positioning only. Planned features are excluded.
- Usage metering into the API usage table, with daily and monthly budget limits enforced server-side and approximate costs shown in the UI.

## Milestone 5 — SORTED Intelligence assistant

- A chat assistant grounded in database records, with tool calls for: query opportunities, list follow-ups, run a new search (real Brave / Companies House call), draft outreach.
- Source links in every answer. It never claims to have searched without making a real tool call.

## Milestone 6 — Growth Advisor and analytics

- Weekly Strategy, Opportunity Analysis, Sales Preparation, Network Opportunities and Progress Review, all generated from real pipeline data.
- Conversion metrics over time, a time-in-stage bottleneck view, and revenue tracking that keeps confirmed MRR separate from estimates.

## Milestone 7 — Hardening

- Acceptance test run-through (sign-in → search → save → assess → outreach → pipeline → task → reload → co-founder → CSV export).
- Provider-failure and missing-key tests, mobile polish, accessibility pass, data export of all tables.
